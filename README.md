## 01 · 团队简介

地球信息智能探测研究团队隶属于**中海油田服务股份有限公司—电子科技大学测井定向井联合研究院**，同时也是电子科技大学信息地学特色研究中心地学仪器研究所的核心组成团队。

联合研究院同时挂牌中国海油测井与定向钻井重点实验室电子分室，是中国海洋石油集团有限公司深水油气装备产业联盟成员单位。

团队现有高级职称教师 **3名**、博士研究生 **7名**、硕士研究生 **30余名**。

## 02 · 研究定位

以认识地球、探测地下油气资源为目标，促进和发展我国地球探测技术。依托电子科技大学在电子信息领域的综合优势，以地球科学领域各类仪器设备电子化、智能化为主要方向，开展地下探测仪器装备的研究与开发，研制具有自主知识产权的地下探测仪器装备。

## 03 · 主要研究方向

团队立足于声、电与核物理基本理论，结合前沿电子信息技术，开展油气智能化探测理论及技术研究。

- **随钻声波测井：** 随钻声波测量、信号采集与处理技术。
- **随钻中子密度测井：** 中子、密度测量方法及井下采集处理电路。
- **油气套管无损检测：** 基于电磁涡流技术的套管损伤检测。
- **智能探测技术：** 人工智能、高性能计算及自动化检测技术。

## 05 · 仪器研发与产业化应用

团队参与研制的系列阵列声波测井仪、微电阻率扫描成像测井仪、随钻中子测井仪及随钻密度测井仪，已经实现批量生产，并在油田生产中推广应用，创造了良好的社会效益和经济效益。

团队持续面向深层、超深层油气资源勘探开发需求，开展高性能地下探测仪器、井下电子系统及智能化测量技术研究，推动地球信息探测技术与仪器装备的自主研发和工程化应用。
