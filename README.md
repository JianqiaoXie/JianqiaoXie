# 地球信息智能探测研究团队

## 团队简介

地球信息智能探测研究团队隶属于中海油田服务股份有限公司—电子科技大学测井定向井联合研究院，同时也是电子科技大学信息地学特色研究中心地学仪器研究所的核心组成团队。

中海油田服务股份有限公司—电子科技大学测井定向井联合研究院同时挂牌中国海油测井与定向钻井重点实验室电子分室，是中国海洋石油集团有限公司深水油气装备产业联盟成员单位。

团队现有高级职称教师3名、博士研究生7名、硕士研究生30余名。

## 研究定位

团队所在学科为仪器科学与技术，具有一级学科博士学位授予权。

团队以认识地球、探测地下油气资源为目标，致力于促进和发展我国地球探测技术。依托电子科技大学在电子信息领域的综合优势，以地球科学领域各类仪器设备的电子化、智能化为主要方向，开展地下探测仪器装备的研究与开发，研制具有自主知识产权的地下探测仪器装备。

近年来，团队在地球信息探测仪器前沿领域取得了一系列研究成果，在国内具有一定影响力，形成了较好的技术积累和研究基础。

## 主要研究方向

团队立足于声、电与核物理基本理论，结合前沿电子信息技术，开展油气智能化探测理论及技术研究。

主要研究方向包括：

- **随钻测井技术：** 随钻声波测井、随钻中子密度测井等井下信息探测技术。
- **油气套管无损检测：** 基于电磁涡流等技术的油气套管损伤检测与评价。
- **地球物理仪器研发：** 地下探测仪器、井下测量电路及专用测试系统设计。
- **智能探测技术：** 结合人工智能、高性能计算及电子信息技术，开展测井信号处理与智能化探测研究。

研究内容涉及地球物理、电子信息技术、人工智能、高性能计算及自动化检测系统等多个领域。

## 代表性研究

1. 随钻声波测井仪器及井下信号采集与处理系统。
2. 随钻中子、密度测井仪器及高温井下电子电路。
3. 油气套管电磁涡流无损检测技术与仪器。
4. 地球物理探测仪器及智能化测量技术。

## 仪器研发与产业化应用

团队参与研制的系列阵列声波测井仪、微电阻率扫描成像测井仪、随钻中子测井仪及随钻密度测井仪，已经实现批量生产，并在油田生产中推广应用，创造了良好的社会效益和经济效益。

团队持续面向深层、超深层油气资源勘探开发需求，开展高性能地下探测仪器、井下电子系统及智能化测量技术研究，推动地球信息探测技术与仪器装备的自主研发和工程化应用。
